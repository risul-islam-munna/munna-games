Dual Play Push Admin

This tool does not store Firebase credentials. To send a notification, provide a temporary Google OAuth access token. An unlinked URL is not authentication — the token is the only authorization boundary.

1 · Credential

Never paste a Firebase service-account private key here. Use only a short-lived OAuth access token with permission to send Firebase Cloud Messaging messages.

Credential stored only in this page's memory. Refreshing the page clears it.

2 · Environment & app

Environment (selects which hosted config is loaded)

Both environments use the same Firebase project and topics — there is no separate dev topic. Environment changes only which config is used to build and preview the message.

App
Dual Play dev.munna.games.dualplay

3 · Notification

Notification type
No URL is sent. The app resolves the trusted update link from the hosted config, and only shows the prompt if the installed build is older than the latest or below the minimum.
Advanced: app-side gates
These values do not prevent Android from receiving/showing a system-tray notification. Use FCM topic/condition targeting to control actual delivery.

4 · Audience

Audience preset
This can reach every subscribed Dual Play install, including older app versions.

Country targeting uses the device locale region. It does not represent GPS, IP, SIM or Google Play country.

Builds

Timezone targeting is not scheduling: Send Now delivers immediately to devices in that zone. Scheduled delivery requires a trusted backend/serverless scheduler.

Safest first test. Debug builds log the device token ([push] FCM token: …). Held in memory only.
